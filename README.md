## Repository Structure

This repository documents research, material exploration, and design development for the Circular Tectonics travelling studio, with focus on GFRC fabrication, timber tectonics synthesis, and circular construction methodologies.

### Folders

- **01_Weekly_Tasks** — Weekly milestones, deliverables, progress tracking, and the repeatable `WEEKLY_WORKFLOW.md` process (brief summary → resources → Miro content → slides → script → references)
- **02_Project_Info** — Official brief (`Official_Brief/`), rebuilt README + exact TIMELINE, `ASSESSMENT_FRAMEWORK.md`, learning outcomes
- **03_Resources** — References, tools, code, Rhino files, and external links
- **04_Pictures** — Sketches, renders, photography, and diagrams
- **05_Material_Research** — GFRC testing, timber specs, circular materials exploration, structural testing
- **06_Precedent_Research** — Case studies, circular practice analogues, relevant precedents

## Key Research Areas

### Material Systems
- GFRC facade + timber hybrid systems
- Circular material strategies (reclaimed, bio-based)
- Fabrication constraints & optimization

### Tectonic Expression
- Multi-agent behaviour in material assembly
- Structural logic as design driver
- Fabrication-aware form generation

### Circular Methodology
- Design for disassembly
- Material loops and end-of-life strategies
- Zero-waste fabrication workflows
