## How to use this vault
- **Graph view** (left ribbon icon): shows how material, precedent, and fabrication notes actually connect — useful for spotting an under-researched chain.
- **Canvas**: [[09_Systemic_Design_Framework/Systemic_Framework.canvas]] is a visual board of the 11 material→fabrication→precedent chains from the systemic map. Drag in new note cards as research grows; connect them the same way.
- **Templates**: `00_Templates/` holds quick-capture note formats (material test, precedent case study, fabrication method, weekly quick note) that link back into the numbered folders. These are for informal notes — the structured weekly deliverables still live in `01_Weekly_Tasks/Week_Template/`.
- **Backlinks pane** (bottom-right of any note): every time you add a `[[wikilink]]` to a note from elsewhere, it shows up here — this is how the vault stays connected instead of becoming a flat pile of files.
- **Git**: this vault *is* the GitHub repo. Commit and push the same way as before (see [[SETUP]]) — `.obsidian/workspace.json` is gitignored (that's just your window layout), but the plugin/theme/template config is versioned so it's the same for anyone who clones the repo.
