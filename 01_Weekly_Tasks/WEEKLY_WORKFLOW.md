# Weekly Workflow — How I'll Process Each Assigned Brief

**Purpose:** Every week I'll receive a tutorial brief/task. This document defines the repeatable process I follow with Claude to turn that brief into a tutorial-ready package: summary, resources, Miro-ready slide content, explanation slides, presentation script, and reference list.

---

## The 6-Step Process

### Step 1 — Brief Summary
When you paste/upload the week's brief, I will produce:
- **1-paragraph plain-English summary** of what's being asked
- **Deliverables checklist** (what must be shown/submitted this week)
- **How it connects** to the phase we're in (see `02_Project_Info/TIMELINE.md`) and to the assessment criteria (see `ASSESSMENT_FRAMEWORK.md`)
- **Open questions/ambiguities** I'll flag rather than guess at

### Step 2 — Resource Finding
I will web-search and compile:
- 3–6 precedents directly relevant to that week's specific task (not generic circular architecture — targeted)
- Technical/software resources if the week involves new tools (Rhino/Grasshopper/Ameba/Fologram tutorials)
- Academic or material-science references if relevant
- All saved into that week's folder as `Week_XX_References.md`

### Step 3 — Miro Board Content (Slide-Ready)
**Note on Miro:** I don't have a direct Miro connector in this workspace, so I can't push content to a live Miro board automatically. What I *can* do:
- Build a structured content outline (frames, sticky-note text, headers, image search terms) formatted so you can **copy-paste directly into Miro** frame-by-frame
- Generate any diagrams/charts as standalone images (via the visualization tool) that you upload as Miro image blocks
- If you'd like, I can check whether a Miro MCP connector is available to connect for direct board editing — just ask and I'll search the connector directory

### Step 4 — Explanation Slides
A markdown/HTML slide outline: one slide = one concept, with:
- Slide title
- 3–5 bullet points max (tutorial pace, not essay pace)
- Suggested visual (diagram, precedent image, my own work-in-progress photo)

### Step 5 — Presentation Script
A **spoken-word script** (not slide text) — what I'd actually say out loud for each slide, timed to ~60–90 seconds per slide, written in first person as if I'm presenting.

### Step 6 — Reference List
Formatted list (Harvard or simple hyperlinked format) of every source used that week, separated into:
- Precedents (built/academic projects)
- Technical/software resources
- Academic papers/articles

---

## What I Need From You Each Week

To run this process efficiently, please provide:
1. The week's brief/task (paste text, or upload PDF/image)
2. Anything you've already produced (sketches, model photos, Grasshopper screenshots) — upload so I can reference it directly rather than guessing
3. Any specific angle/material/precedent you want emphasized
