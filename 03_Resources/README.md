# Resources

Central location for tools, references, code, and Rhino files.

## Subfolders

### References/
Academic papers, articles, books, and web links on:
- Circular economy in architecture
- GFRC fabrication techniques
- Timber hybrid systems
- Tectonic theory

### Tools/
Software links, plugins, and workflows:
- Rhino / Grasshopper scripts
- FEA tools (Karamba, Ladybug)
- Fabrication CAM software
- Simulation environments

### Code/
Python scripts, grasshopper definitions, and custom tools:
- Material property calculators
- Fabrication offset scripts
- Optimization algorithms
- Data processing utilities

### Rhino-Files/
3D models, working files, and component libraries:
- Material libraries
- Timber profile definitions
- GFRC facade components
- Assembly prototypes

---

## How to Organize

- **References:** Use folder structure like `References/Circular-Economy/`, `References/GFRC-Fabrication/`
- **Tools:** Include usage notes and version info
- **Code:** Add `README.md` inside each script folder explaining inputs/outputs
- **Rhino-Files:** Version files with dates, tag design iterations
