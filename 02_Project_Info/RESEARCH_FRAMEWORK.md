# Research Framework & Methodologies

This document outlines systematic approaches for each research stream in the studio.

---

## 1. Material Research Framework

### 1.1 GFRC Research

**Objectives:**
- Understand GFRC mix design and performance variables
- Test surface finishes and color strategies
- Evaluate fabrication tolerances
- Develop connector design logic

**Research Stream:**
```
Mix Design → Testing → Iteration → Performance Documentation → Specification
```

**Key Tests:**
- Compressive strength
- Flexural strength
- Impact resistance
- Water absorption
- UV durability
- Surface finish quality

**Documentation Template:**
```
TEST GFRC-[Date]-[Variable]
Date: YYYY-MM-DD
Variable Tested: [What changed?]
Mix Design: [Proportions]
Cure Time: [Days at X°C]

RESULTS:
- Strength: X MPa
- Observations: [Visual/tactile qualities]
- Photos: [Clear lighting, scale reference]

IMPLICATIONS:
- Can we use this for [component]?
- Next test direction?
```

---

### 1.2 Timber Research

**Objectives:**
- Document local timber species available
- Test connection detailing with reclaimed timber
- Evaluate durability treatments
- Establish fabrication tolerances

**Research Stream:**
```
Species ID → Properties Test → Connection Detailing → Durability → Specification
```

**Key Information to Capture:**
- Species (common + scientific name)
- Strength class (per relevant standard)
- Availability in reclaimed market
- Suitable applications
- Connection strategies
- Treatment/finishing recommendations

**Documentation Template:**
```
TIMBER SPECIES: [Name]
Source: [Where sourced]
Dimensions: [Typical reclaimed sizes]
Strength Class: [Per EN/AS standard]

PROPERTIES:
- Density: X kg/m³
- MOE: X GPa
- Bending Strength: X MPa
- Compression: X MPa

DETAILING NOTES:
- Preferred connections: [Joint types]
- Fastening: [Bolts/screws/dowels]
- Fabrication tolerance: ±X mm
- Finishing: [Treatment/sealing]

LOCAL AVAILABILITY:
- Cost: $X per m³
- Lead time: X weeks
- Supplier: [Contact info]
```

### 1.3 Circular Materials Research

**Objectives:**
- Map available reclaimed material streams in HK context
- Evaluate environmental benefits vs virgin materials
- Develop sourcing strategies
- Create material passport templates

**Research Stream:**
```
Material Stream Mapping → Availability Assessment → Environmental Audit → Sourcing Protocol
```

**Key Research Areas:**
- Reclaimed structural steel
- Reclaimed timber
- Reclaimed concrete/aggregates
- Salvaged architectural components
- Bio-based alternatives (cork, bamboo, straw, etc.)
- Recycled content materials

**Documentation Template:**
```
MATERIAL: [Name]
Category: [Reclaimed/Recycled/Bio-based]
Source Stream: [Demolition waste/Industrial byproduct/Renewable]

ENVIRONMENTAL PROFILE:
- Embodied carbon: X kg CO2e per unit
- vs Virgin equivalent: Y kg CO2e per unit
- Carbon saved: Z%
- Recyclability: [Yes/No/Partial]

AVAILABILITY IN HK:
- Typical suppliers: [List]
- Lead time: X weeks
- Cost: $X per unit
- Quality variability: [High/Medium/Low]

APPLICATIONS:
- Suitable for: [Component types]
- Performance requirements: [What's needed]
- Connection strategies: [How to join]
```

### 1.4 Connector & Joint Research

**Objectives:**
- Develop 3D-printed connector language
- Test flexibility/accommodation of dimensional variation
- Evaluate material options (resin, nylon, etc.)
- Create assembly instructions

**Research Stream:**
```
Connection Logic → Prototype → Testing → Refinement → Documentation
```

**Key Connector Types to Explore:**
- Flexible ball-and-socket joints
- Linear accommodation connectors
- Angular transition joints
- Multi-directional hubs
- Custom bridging elements

**Testing Protocol:**
- Load testing (axial, shear, bending)
- Fatigue testing (repeated assembly/disassembly)
- Environmental exposure (UV, moisture, temperature cycling)
- Assembly ease/clarity

## 2. Precedent Research Framework

### Research Methodology

**For each precedent studied, document:**

```
1. PROJECT CONTEXT
   - Architect/firm
   - Date/location
   - Scale/program
   - Budget/timeline

2. DESIGN STRATEGY
   - Conceptual framework
   - Material selection rationale
   - Structural system
   - Environmental/circular approach

3. TECTONIC EXPRESSION
   - How is the building constructed?
   - What material/joints are visible?
   - How does fabrication logic appear?
   - Aesthetic/philosophical intent

4. FABRICATION METHODOLOGY
   - Custom fabrication? Where?
   - Off-site assembly vs on-site?
   - Precision requirements?
   - Special equipment/skills?

5. CIRCULAR/SUSTAINABILITY STRATEGY
   - Material sourcing
   - Design for disassembly features
   - End-of-life planning
   - Embodied carbon strategies

6. RELEVANCE TO OUR RESEARCH
   - What can we learn?
   - Applicable techniques?
   - Design principles?
   - Cautions/warnings?
```

## 3. Digital Fabrication Research Framework

### 3.1 3D Scanning & Point Cloud Research

**Workflow:**
```
Physical Component → Scanning → Point Cloud Processing → Classification → Database Entry
```

**Key Learnings to Document:**
- Optimal scanning resolution/settings
- Processing workflows (CloudCompare, Meshlab)
- Classification schemas (material, size, condition)
- Database structure for future reference

---

### 3.2 Computational Form-Finding Research

**Framework:**
```
Material Constraints → Algorithmic Generation → Structural Validation → Fabrication Feasibility
```

**Key Variables:**
- Material availability (quantity, dimensions, condition)
- Structural requirements (loads, spans, safety factors)
- Fabrication constraints (tolerances, tooling, assembly)
- Aesthetic/tectonic expression

---

### 3.3 3D Printing & Connectors

**Research Areas:**
- Material selection (SLA resin, FDM nylon, etc.)
- Print orientation & support strategies
- Post-processing for assembly-ready parts
- Quality control and dimensional accuracy
- Cost optimization (material waste, print time)

**Testing Framework:**
- Prototype connectors under load
- Assembly/disassembly cycles
- Durability in outdoor conditions
- Precision of 3D-printed joinery

## 6. Research Documentation Standards

### File Organization
- **Dates:** YYYY-MM-DD format
- **Descriptions:** Clear, searchable filenames
- **Images:** High resolution, consistent lighting/scale
- **Data:** Spreadsheets with headers and units

### README Pattern
Each research area should include:
- Research objective
- Methodology
- Results summary
- Key findings
- Recommended next steps
- Related files/links

### Cross-referencing
- Link related experiments
- Reference precedents in material/connector research
- Connect design iterations to research findings
- Build cumulative knowledge base
